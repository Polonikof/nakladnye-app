# Для нового чата — как продолжить этот проект

Положите этот файл (и при необходимости `VtebskieKovri_ДОКУМЕНТАЦИЯ.md`) в начало нового чата.

**Не собирайте программу с нуля.** Это уже готовое оконное приложение на Python + Tkinter, сборка в один `Накладные.exe`.

## Что это

Программа переводит накладные поставщиков в формат для учётной программы.

| Тип | Вход | Результат |
|---|---|---|
| Витебские ковры | `.xls` фактура | `*_VITEBSK_Обработано.xlsx` |
| Обои (УПД ВВП) | `.xlsx` УПД | `*_ОБОИ_Обработано.xlsx` |

Рабочая папка на ПК: `C:\Накладные`  
Папка обучения новым форматам: `C:\Накладные\НовыеНакладные`

Текущая версия окна: **1.2**. После «Обучить» программа копирует себя в `Накладные_1.2.1.exe` (номер растёт). Версия 1.0 кнопки «Обучить» не имеет.

## Как пользуется Дмитрий

1. Обычные накладные кладёт в `C:\Накладные` → кнопка **Обработать файлы**.
2. Чтобы научить программу новой накладной, кладёт в `C:\Накладные\НовыеНакладные` **два файла**:
   - как пришло (в имени слово `исходник`)
   - как сделал руками (в имени слово `готовый`)
   → кнопка **Обучить**.
3. Агент дописывает артикулы в `oboi_catalog.json`, поднимает версию и кладёт новый файл `Накладные_1.2.1.exe` в `C:\Накладные` (и копию в `релизы\`).

Подробно для человека: `КАК_РАБОТАТЬ.txt`.

## Главные файлы

| Файл | Зачем |
|---|---|
| `nakladnye_app.py` | Окно (кнопки, журнал). Версия берётся из `version.txt` или `BUILT_IN_VERSION` |
| `convert_nakladnaya.py` | Обработка ковров и обоев |
| `learn_novye.py` | Обучение по папке НовыеНакладные |
| `oboi_catalog.json` | Справочник артикул → код УТ + короткое имя |
| `nakladnye.spec` | Сборка PyInstaller |
| `release/Накладные.exe` | Готовая Windows-сборка 1.1 |
| `VtebskieKovri_ДОКУМЕНТАЦИЯ.md` | Правила разбора ковров, не ломать |
| `samples/` | Эталон УПД обоев |

## Сборка exe

На Windows: `build_exe.bat`  
На GitHub: workflow `.github/workflows/build-windows-exe.yml` (по тегу `v*`).

Готовый файл также на Releases репозитория.

## Проверка обоев

```bash
pip install -r requirements.txt
python convert_nakladnaya.py --force \
  "samples/ВВП УПД 04.09.26 № 00УТ-011419 source.xlsx" \
  samples/out_oboi.xlsx
python compare_oboi.py samples/out_oboi.xlsx "samples/ВВП УПД 04.09.26 готовый.xlsx"
```

Ожидается: `OK: 0 расхождений`.

## Чего не делать

- Не переписывать программу на Next.js / сайт.
- Не менять опечатку `ПолноеНаименвоание` в выходном файле ковров — так нужно учётке.
- Не требовать Python на рабочем ПК: пользователь запускает один `.exe`.
