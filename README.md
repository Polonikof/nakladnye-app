# Накладные: Витебск + Обои

Переводит накладные поставщиков в формат для загрузки в учётную программу.

| Тип | Вход | Результат |
|---|---|---|
| Витебские ковры | `.xls` фактура | `*_VITEBSK_Обработано.xlsx` |
| Обои (УПД ВВП) | `.xlsx` УПД с длинными именами | `*_ОБОИ_Обработано.xlsx` |

Полная история решений и правила разбора — в [`VtebskieKovri_ДОКУМЕНТАЦИЯ.md`](VtebskieKovri_ДОКУМЕНТАЦИЯ.md).

## По шагам: обучить программу новой накладной

Когда поставщик прислал формат, которого ещё нет в `Накладные.exe`:

1. **Создайте папку** `C:\НовыеНакладные`  
   Двойной щелчок по `Создать_папку_НовыеНакладные.bat`  
   или в окне программы кнопка «Создать папку НовыеНакладные».

2. **Положите туда два файла одной накладной**
   - исходник (как пришло) — в имени `source` или `исходник`
   - готовый (как обработали руками) — в имени `готовый`

   Пример:
   `ВВП УПД 04.09.26 source.xlsx`  
   `ВВП УПД 04.09.26 готовый.xlsx`

3. **Запустите агента** — он сам увидит пару:
   - кнопка «Обучить из НовыеНакладные» в `Накладные.exe`
   - или `Следить_за_НовыеНакладные.bat` (окно можно оставить открытым)

4. **Агент разбирает файлы**: читает эталон, дописывает артикулы
   в `oboi_catalog.json`, прогоняет исходник и сверяет с готовым.
   Отчёт лежит в `C:\НовыеНакладные\_архив`.

5. **Новый релиз `Накладные.exe`**  
   Положите обновлённый `oboi_catalog.json` рядом с `.exe` — программа
   возьмёт его сразу, без пересборки.  
   Чтобы вшить справочник внутрь нового `.exe`: `build_exe.bat`.
   Запись о обучении — `release/LEARNED.md`.

## Приложение для ПК (один файл, без установки)

`Накладные.exe` — оконное приложение: одна кнопка «Обработать файлы»,
журнал работы прямо в окне и сводка о готовности по окончании.
Python на рабочем компьютере не нужен, всё вшито в один файл.

Готовый файл — на странице
[Releases](https://github.com/Polonikof/nakladnye-app/releases/latest)
(`Nakladnye.exe`, ~11,4 МБ, 64-битная Windows). Та же сборка лежит в
репозитории: [`release/Накладные.exe`](release/). Скачайте любой из двух
и пользуйтесь — собирать ничего не нужно.

### Как пользоваться

1. Положите `Накладные.exe` в рабочую папку с накладными (например `C:\Накладные`).
2. Скопируйте туда же новые накладные (`.xls` от Витебска и/или сырой УПД `.xlsx` по обоям).
3. Запустите `Накладные.exe` двойным щелчком.
4. Нажмите «Обработать файлы».

Ход работы построчно появляется в журнале, а по окончании выводится сводка:
сколько файлов обработано, сколько строк перенесено, какие файлы созданы
и сколько заняла работа. Результаты лежат рядом с исходниками, с суффиксом
`_Обработано`.

Что ещё есть в окне:

| Элемент | Зачем |
|---|---|
| Папка с накладными | По умолчанию — папка, где лежит сам `.exe`. Можно выбрать другую. |
| Обрабатывать повторно | Игнорирует журнал `.vitebsk_processed.json` и обрабатывает файлы заново. |
| Открыть папку с результатами | Открывает рабочую папку в проводнике. |
| Сохранить журнал… | Выгружает содержимое журнала в текстовый файл. |

Приложение запоминает обработанные файлы в `.vitebsk_processed.json` рядом
с накладными, поэтому повторный запуск не создаёт дубликатов.

При первом запуске Windows может показать предупреждение SmartScreen
(файл без цифровой подписи) — «Подробнее» → «Выполнить в любом случае».

### Сборка `.exe` из исходников

На компьютере с Windows и Python 3.9+ (нужен один раз, на рабочем ПК не требуется):

```bat
build_exe.bat
```

Скрипт поставит зависимости и соберёт `dist\Накладные.exe`.

| Скрипт | Где запускать | Что собирает |
|---|---|---|
| `build_exe.bat` | Windows | `dist\Накладные.exe` |
| `build_exe_wine.sh` | Linux, есть wine | `dist-win/Накладные.exe` (для Windows) |
| `build.sh` | Linux / macOS | `dist/Накладные` (для этой же системы) |

`build_exe_wine.sh` нужен, чтобы собрать Windows-версию, не имея Windows:
он поднимает portable Windows-Python под wine и прогоняет тот же
`nakladnye.spec`.

## Состав репозитория

| Файл | Назначение |
|---|---|
| `nakladnye_app.py` | Оконное приложение (кнопка + журнал + сводка) |
| `convert_nakladnaya.py` | Логика обработки (ковры + обои), она же CLI |
| `learn_novye.py` | Агент обучения по папке «НовыеНакладные» |

| `Следить_за_НовыеНакладные.bat` | Следит за папкой и запускает агента |
| `nakladnye.spec` | Конфигурация PyInstaller для сборки в один файл |
| `build_exe.bat` / `build.sh` / `build_exe_wine.sh` | Сборка одного исполняемого файла |
| `release/Накладные.exe` | Готовая сборка для Windows |
| `Обработать_накладные.bat` | Запуск обработки без окна, из консоли |
| `oboi_catalog.json` | Справочник артикул → код УТ + короткое имя |
| `compare_oboi.py` | Сверка результата с эталоном «готовый» |
| `samples/` | Исходник и эталон УПД 04.09.26 |
| `requirements.txt` | Зависимости для запуска из исходников |
| `requirements-build.txt` | Зависимости для сборки `.exe` |

## Запуск из исходников

```bash
pip install -r requirements.txt

python nakladnye_app.py            # оконное приложение
python convert_nakladnaya.py       # обработать все новые файлы в текущей папке
```

Командная строка целиком:

```bash
python convert_nakladnaya.py
python convert_nakladnaya.py "файл.xlsx"
python convert_nakladnaya.py "файл.xlsx" --force
python convert_nakladnaya.py --learn-oboi "ВВП УПД … готовый .xlsx"
python convert_nakladnaya.py --setup-inbox
python convert_nakladnaya.py --learn-inbox
python learn_novye.py --watch
```

## Обои: справочник

Короткие имена и коды `УТ…` берутся из `oboi_catalog.json` (ключ — артикул).
Эталон из `samples/` уже занесён в справочник (50 позиций).
Новый эталон «готовый» подключайте через `--learn-oboi` или папку «НовыеНакладные».

Справочник вшивается в `.exe` при сборке. Если положить свой
`oboi_catalog.json` рядом с `.exe`, приложение возьмёт именно его — так
справочник можно обновлять без пересборки.

## Проверка на образцах

```bash
python convert_nakladnaya.py --force \
  "samples/ВВП УПД 04.09.26 № 00УТ-011419 source.xlsx" \
  samples/out_oboi.xlsx

python compare_oboi.py samples/out_oboi.xlsx "samples/ВВП УПД 04.09.26 готовый.xlsx"
```

Ожидаемый результат: `OK: 0 расхождений`.
